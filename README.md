# Calculator

A small calculator made with Godot 4.7. It has a hand drawn style and some jokes hidden inside.

## Features

* Basic math: add, subtract, multiply, divide
* Extra keys: clear, backspace, percent, sign change, decimal point
* Keyboard support
* Hand drawn buttons and display
* Fun effects for special results

## Easter eggs

* Try `9 + 10 =`
* Try to get `67` as a result
